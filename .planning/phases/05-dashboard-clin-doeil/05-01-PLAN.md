**Algorithme derivePriorityCards(computedRatios: ComputedRatio[]) :**

1. Séparer les ratios en 3 groupes :
   - `weak` = status "danger" ou "warning", trié par percentageOfTarget croissant (plus loin du seuil = pire)
   - `stable` = status "ok", trié par percentageOfTarget décroissant (meilleur % en premier)
   - `strong` = status "ok" ET percentageOfTarget >= 100

2. **Card rouge** = `weak[0]` → severity "rouge"
   - Si `weak` vide : prendre le ratio avec percentageOfTarget le plus bas parmi tous → severity "rouge" mais verdict "À surveiller"

3. **Card orange** = `weak[1]` si existe, sinon `stable[0]` (ratio OK mais pas en surperf) → severity "orange"
   - Si aussi vide : dupliquer le weak[0] avec un verdict différent "Second point à travailler"

4. **Card vert** = premier ratio avec status "ok" ET percentageOfTarget >= 100, sinon stable[0] ≠ card orange, sinon strong[0] → severity "vert"
   - Priorité absolue : un ratio genuinement en surperf pour célébrer

5. **Pour chaque card, construire PriorityCard :**

   a. **verdict** (phrase FR courte) :
   - rouge : "Ton ratio [label] est sous le seuil ({value} vs cible {threshold})"
   - orange : "Ton ratio [label] est à surveiller ({value} vs cible {threshold})"
   - vert : "Ton ratio [label] est en excellente forme ({value} vs cible {threshold}) 👏" — OK d'utiliser les caractères réels

   b. **metric** : `{ value: ratio.value, target: ratio.thresholdForCategory, unit: ratioId.includes("pct") ? "%" : "" }`

   c. **action** (per D2) :
   - rouge/orange + ratioId dans RATIO_SITUATION_MAP → `{ label: "Lancer le training " + situation, href: "/conseiller/training/" + situation, type: "training" }`
   - rouge/orange + ratioId pas dans RATIO_SITUATION_MAP → `{ label: "Voir le diagnostic", href: "/conseiller/diagnostic?highlight=" + ratioId, type: "view-ratio" }`
   - vert → `{ label: "Voir le détail", href: "/conseiller/diagnostic?view=ratios&highlight=" + ratioId, type: "view-ratio" }`
