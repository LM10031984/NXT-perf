**Derivation algorithm (D1 — no LLM call):**
1. Sort `computedRatios` by severity: `danger` first, then `warning`, skip `ok`
2. Take the top 3 (or fewer if < 3 under-performing ratios)
3. For each ratio, build a `SuggestionCard`:
   - `id`: `"suggestion-${ratio.ratioId}"`
   - `kind`: map `ratioId` → `"training"` for ratio-related ratios, `"saisie"` if no ratios available
   - `label`: short verdict string (see mapping below)
   - `prompt`: natural-language coaching request

**Label + prompt mapping per ratio:**
