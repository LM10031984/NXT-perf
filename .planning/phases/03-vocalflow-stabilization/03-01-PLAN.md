**Step A — Implement `src/lib/transcription.ts`** (replace stub from 03-00):

The function wraps the `/api/vocal` fetch call with:
- `AbortController` + `setTimeout(reject, opts?.timeoutMs ?? 10_000)` — abort on timeout → return `{ ok: false, error: "timeout" }`
- Retry loop: max 3 attempts, only on HTTP 429 → backoff 1000ms, 2000ms, 4000ms via `await new Promise(r => setTimeout(r, delay))`
- HTTP 400 with empty transcript → `{ ok: false, error: "audio-invalid", details: response.error }`
- HTTP 5xx or network error → `{ ok: false, error: "unknown", details: message }`
- HTTP 200 → `{ ok: true, text: data.transcript, latencyMs: Date.now() - start }`
- `latencyMs` measured as `Date.now()` before fetch minus `Date.now()` after successful parse
- The function receives `audio: Blob | File` and a `section` parameter

IMPORTANT: `transcribeAudio` in `transcription.ts` only handles the Groq Whisper step (step 1 of `/api/vocal`). The extraction (step 2 — OpenRouter) remains in the route. The function posts to `/api/vocal` with the audio blob and section, returns the transcript string on success. This matches the existing route contract.

Wait — re-read the route. `/api/vocal` does BOTH transcription AND extraction. `transcribeAudio` wraps the entire `/api/vocal` call, not just the Groq part. The `text` field in `TranscriptionResult` maps to `data.transcript` from the route response. The `extracted` and `section` fields from the route response are handled by `processAudio()` in the hook, which calls `transcribeAudio` first.

Revised design: `transcribeAudio(audio, opts)` posts to `/api/vocal` with `{ audio, section }` — WAIT, `section` is required by the route. The signature needs to include section. But CONTEXT.md D2 shows `transcribeAudio(audio, opts)` without section. Resolve this by adding section as a required second parameter:

```typescript
export async function transcribeAudio(
  audio: Blob | File,
  section: string,
  opts?: { timeoutMs?: number }
): Promise<TranscriptionResult>
```

This is a minor deviation from D2's signature — justified because the route requires it. Document in the file header.
