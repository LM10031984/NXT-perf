**Step A — Create `src/components/vocal/VocalDrawer.tsx`**:

A thin Sheet (drawer) component that wraps VocalFlow. The trigger is a primary button with mic icon labeled "Saisir mes chiffres à la voix" (per D4, CONTEXT.md).

```typescript
"use client";

import { useState } from "react";
import { Mic } from "lucide-react";
import { VocalFlow } from "./VocalFlow";
import { useWeeklyGate } from "@/hooks/use-weekly-gate";
import type { PeriodResults } from "@/types/results";
import { cn } from "@/lib/utils";
// Check if Sheet component exists in src/components/ui/sheet.tsx
// If yes, import from there. If not, use Radix Dialog primitive directly.

interface VocalDrawerProps {
  className?: string;
}

export function VocalDrawer({ className }: VocalDrawerProps) {
  const [open, setOpen] = useState(false);
  const { submissionStatus, markSaisieDone } = useWeeklyGate();

  // Per D4: only show when weekly results are missing
  if (submissionStatus === "done") return null;

  const handleComplete = async (data: Partial<PeriodResults>) => {
    // data is passed to caller via onComplete — here we just close and mark done
    await markSaisieDone();
    setOpen(false);
  };

  return (
    <>
      <button
        onClick={() => setOpen(true)}
        className={cn(
          "flex items-center gap-2 rounded-[var(--radius-button)] bg-primary px-4 py-3 text-sm font-semibold text-primary-foreground shadow-sm transition-all hover:brightness-110 active:scale-95",
          className
        )}
        aria-label="Saisir mes chiffres à la voix"
      >
        <Mic className="h-4 w-4" />
        Saisir mes chiffres à la voix
      </button>

      {/* Sheet / Drawer — use Radix Sheet primitive */}
      {open && (
        <VocalFlow
          onClose={() => setOpen(false)}
          onComplete={handleComplete}
        />
      )}
    </>
  );
}
```

IMPORTANT: VocalFlow already renders as a fixed overlay (modal). The "drawer" in D4 refers to the UX intent — inline, non-navigating. Because VocalFlow is already a modal overlay, wrapping it in another Sheet would double-layer modals. Use VocalFlow directly (as VocalButton does) — no additional Sheet wrapper needed. The UX goal of "staying on dashboard" is met because VocalFlow is a modal.

If you want to use a Radix Sheet for a true side-drawer look (which matches D4's "drawer/modal" language), check `src/components/ui/sheet.tsx`. If it exists, you MAY use it to wrap VocalFlow's content inside a Sheet. But VocalFlow's fixed-overlay approach already satisfies the requirement — do what requires less code.
