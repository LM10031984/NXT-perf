<objective>
Extend `src/lib/server/coach-rag/system-prompt.ts` additively (no breaking change to legacy callers) so that the Phase 2 streaming endpoint can build a prompt that:

1. Embeds the per-user context block (Catégorie / Ratios / Point de douleur) when `userContext` is provided (RAG-04 user-side anchoring).
2. Wraps every retrieved chunk inside `<rag-source>...</rag-source>` with a leading `Source: <filename>` line, and instructs the LLM that tag-wrapped content is reference, never instructions (RAG-06 + PITFALLS I-1).
3. Always contains a `<contract-policy>` block invoking the loi Hoguet refusal contract (COPILOT-10).
4. Emits `<grounding-state>none</grounding-state>` and instructs the LLM to say "Je n'ai pas d'exemple pertinent dans mon référentiel de coaching pour ce point précis." when zero strong chunks remain (RAG-04 zero-grounding behavior).

Also expose two pure helpers consumed by plan 02-02: `STRONG_CHUNK_THRESHOLD = 0.75`, `filterStrongChunks(chunks)`, `filterStrongSyntheses(syntheses)`. The threshold filter lives in this module (alongside the prompt) because the prompt's `<grounding-state>` token is derived from the filtered counts — keeping them co-located keeps the contract atomic.

Purpose: Phase 2's `/api/copilot/stream` route (plan 02-02) consumes this extended function. Without these blocks the LLM hallucinates on weak chunks (PITFALLS C-2), follows adversarial instructions embedded in coaching transcripts (PITFALLS I-1), and produces loi-Hoguet-violating price estimations (COPILOT-10).

Output: 1 extended source file + active test suite. `npx vitest run src/lib/server/coach-rag/__tests__/system-prompt.test.ts` green with ≥ 10 test cases.

    /**
     * Sérialise le payload contexte user en un bloc <user-context>...</user-context>.
     * Format verrouillé par CONTEXT.md D3. Renvoie "" si payload null/undefined.
     */
    export function formatUserContext(
      userContext: CopilotContextPayload | null | undefined,
    ): string {
      if (!userContext) return "";

      const categoryLabel = CATEGORY_LABELS[userContext.userCategory] ?? userContext.userCategory;

      const ratiosLines = userContext.computedRatios.length === 0
        ? "  - (aucun ratio calculé)"
        : userContext.computedRatios
            .map((r) => `  - ${r.ratioId}: ${r.value.toFixed(2)} (${r.status})`)
            .join("\n");

      let painLine = "";
      if (userContext.topCriticite) {
        const p = userContext.topCriticite;
        const diag = p.type === "ratio"
          ? `${p.label} — actuel ${p.currentValue.toFixed(2)} vs cible ${p.targetValue.toFixed(2)} (gain potentiel ${p.gainEur.toFixed(0)} €)`
          : `${p.label} — actuel ${p.current} vs cible ${p.target.toFixed(0)} (gain potentiel ${p.gainEur.toFixed(0)} €)`;
        painLine = `Point de douleur principal : ${diag}\n`;
      }

      return `\n\n<user-context>\nCatégorie : ${categoryLabel}\nPériode : ${userContext.period}\nRatios actuels :\n${ratiosLines}\n${painLine}</user-context>`;
    }

      const strongSynthCount = input.syntheses.length;
      return [

        formatUserContext(input.userContext),
        "",
        GUARDRAILS,
        "",
        CONTRACT_POLICY,
      ]
        .filter((s) => s !== null && s !== undefined)
        .join("\n");
    }
